# 🚆 RailProject – Railway Entry Portal

A web-based Railway Entry Portal built using Java, Spring Boot, HTML, and CSS. This project is designed to streamline railway-related entry management operations through a clean and responsive portal interface.

---

## 📌 Overview

RailProject is a Maven-based Spring Boot application that provides a structured backend and frontend setup for managing railway entry operations. The application follows a modular project structure and can be extended for authentication, ticket management, employee access, passenger handling, or railway administration functionalities.

The project demonstrates:

* Java backend development
* Spring Boot application setup
* Maven dependency management
* Frontend integration using HTML & CSS
* Structured MVC-based architecture

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ShaleenChakraborty/RailProject.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd RailProject
```

### 3️⃣ Run the Application

#### Using Maven Wrapper

For Windows:

```bash
mvnw.cmd spring-boot:run
```

For Linux/Mac:

```bash
./mvnw spring-boot:run
```

---

## ▶️ Running the Application

Once the server starts successfully, open your browser and visit:

```bash
http://localhost:8080
```
